# Build roadmap

1. Project structure (this zip)
2. Run backend locally, seed sample data
3. Run frontend locally, see activities from the API
4. Database: switch SQLite to MySQL or PostgreSQL, add migrations
5. UI design: home, activity cards, hero, images
6. Activity details page: gallery, FAQs, safety
7. Reviews
8. Google login
9. Payments (Razorpay or Stripe)
10. Admin panel: manage activities, bookings, coupons, revenue
11. Weather and Google Maps
12. QR tickets, email and WhatsApp confirmation
13. Multi-language, packages, polish
14. Deploy: Render (backend) and Vercel (frontend)
